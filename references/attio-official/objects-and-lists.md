# Objects and lists

Live: https://docs.attio.com/docs/objects-and-lists

- **Objects** = entity types (people, companies, deals, users, workspaces, custom). A **record** is one instance. **Attributes** are columns.
- Default objects: people, companies. Optional: deal, user, workspace.
- **Lists** group records into a process. Each row is an **entry** with list-only attributes (stage, next step). One record can be in many lists.
- This workspace’s pipelines (Expert Series, Revenue Partner Program, affiliate credits) are lists on People. Deals stay the money object.
